# Learning Journey

My machine learning journey over the years, kept in one place. Each old project of mine is revisited, rebuilt and explained, so you can see where I started and how my skills have grown. Some repositories are written as step-by-step lessons for other learners.

## How this works

- One repository is improved per day, on its own branch, with small commits and a pull request.
- Educational repositories are written like a classroom: intuition first, then a picture, then light math, then small code cells, then check-yourself questions.
- Growth repositories keep the original code in `legacy/` and add a "then vs now" comparison with honest numbers.
- The schedule and the rules are in [PLAN.md](PLAN.md). Conventions are in [docs/conventions.md](docs/conventions.md). Daily notes are in [progress/](progress/).

## Folders

- `templates/`: reusable templates for a repository README, a daily progress note and image credits.
- `progress/`: one short note per working day, plus a running log.
- `docs/`: conventions for commits, branches, notebooks and images.
- `.github/`: pull request template and an automated hygiene check.
